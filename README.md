# 🩺 HealthPro – Android Health Management App

**HealthPro** is an Android-based health management application that allows users to efficiently monitor and manage their health information in one unified platform.  
The app focuses on simplicity, data security, and real-time accessibility, offering users an intelligent way to stay informed about their wellness routines, appointments, and health metrics.

---

## 🌟 Key Features

- **Secure Authentication** – Sign up and log in with Firebase Authentication  
- **Health Record Management** – Add, view, and edit medical history, prescriptions, and test reports  
- **Appointment Tracker** – Schedule and track doctor visits with reminders  
- **Personalized Health Tips** – Get AI-driven suggestions for lifestyle improvement  
- **Emergency Access** – Quickly connect with saved emergency contacts or nearby hospitals  
- **Dashboard Overview** – View critical health data through a clean, interactive interface

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Rohithselvan/Healthpro_Android_App.git
   
2.   Open in Android Studio

      Open Android Studio → File → Open → Select the project folder

3.   Build the Project

      Sync Gradle files and allow dependencies to download

4.   Run the App

      Use an emulator or connect a physical Android device

5.   Login or Sign Up

      Create an account and explore the full set of HealthPro features
